# Reporting a security vulnerability

Use the repository's [private vulnerability reporting form](https://github.com/Kiranaide/Kira-Kit/security/advisories/new).
Include the affected version, impact, and enough detail for a maintainer to
investigate. Keep credentials and identifying project data out of the report.

For ordinary install or component bugs, use [GitHub Issues](https://github.com/Kiranaide/Kira-Kit/issues).
