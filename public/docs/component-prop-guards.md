# Component Prop Guards

Type guards for callback and event props shared across components to keep prop forwarding type-safe.

## Install

```bash
kira-kit add @kira-kit/component-prop-guards
```

## Usage

```tsx
// Installed under your lib alias, e.g. src/lib/component-prop-guards.ts
import { /* exports */ } from "@/lib/component-prop-guards";
```
