# Data Table Helpers

Sorting, filtering, and sample-data helpers used by the data table documentation demos.

## Install

```bash
kira-kit add @kira-kit/data-table-helpers
```

## Usage

```tsx
// Installed under your lib alias, e.g. src/lib/data-table-helpers.ts
import { /* exports */ } from "@/lib/data-table-helpers";
```
