# Magenta Riot

A deep magenta against cool zinc that brings editorial confidence to community platforms, music products, and launch dashboards.

## Install

```bash
npx shadcn add @kira-kit/theme-magenta-riot
```

## Usage

```tsx
import { ThemeMagentaRiot } from "@/components/ui/theme-magenta-riot";
/* Applied as CSS variables by shadcn. */
```
