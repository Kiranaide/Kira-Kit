# Oxblood Atelier

A deep wine-red theme for luxury services, cultural institutions, and membership products that need drama in measured doses.

## Install

```bash
npx shadcn add @kira-kit/theme-oxblood-atelier
```

## Usage

```tsx
import { ThemeOxbloodAtelier } from "@/components/ui/theme-oxblood-atelier";
/* Applied as CSS variables by shadcn. */
```
