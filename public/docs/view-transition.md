# View Transition Utility

Reduced-motion-aware wrapper around the native View Transitions API: runs DOM updates inside document.startViewTransition when supported, and applies them instantly otherwise.

## Install

```bash
kira-kit add @kira-kit/view-transition
```

## Usage

```tsx
// Installed under your lib alias, e.g. src/lib/view-transition.ts
import { /* exports */ } from "@/lib/view-transition";
```
