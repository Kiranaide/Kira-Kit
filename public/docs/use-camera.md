# useCamera

Controls browser camera previews, photo capture, video recording, device switching, zoom, focus, flash, timers, and optional keyboard, gesture, and voice input. It returns videoRef and gestureContainerRef plus stream, permission, device, and capture state and actions, with options for facingMode, media constraints, autoStart, capture format and quality, and lifecycle callbacks.

## Install

```bash
npx shadcn add @kira-kit/use-camera
```

## Usage

```tsx
import { useCamera } from "@/hooks/use-camera";

```
