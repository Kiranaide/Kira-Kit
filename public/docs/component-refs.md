# Component Refs

Merges multiple refs into a single callback ref for composed components such as code block and color picker.

## Install

```bash
kira-kit add @kira-kit/component-refs
```

## Registry dependencies

- @kira-kit/component-prop-guards

## Usage

```tsx
// Installed under your lib alias, e.g. src/lib/component-refs.ts
import { /* exports */ } from "@/lib/component-refs";
```
