# useColorPicker

Manages controlled or uncontrolled HSVA color and alpha state and returns setters, recent colors, generated harmonies, contrast ratios, formatting, and clipboard-copy helpers. Use it to build color-picker interfaces with value/defaultValue, onValueChange, showAlpha, maxRecentColors, disabled, and readOnly options.

## Install

```bash
npx shadcn add @kira-kit/use-color-picker
```

## Dependencies

- @uiw/color-convert

## Usage

```tsx
import { useColorPicker } from "@/hooks/use-color-picker";
```
