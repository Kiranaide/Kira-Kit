# Color Picker Math

Color parsing, format conversion, and accessible-contrast math powering the color picker component and hook.

## Install

```bash
kira-kit add @kira-kit/color-picker-lib
```

## Dependencies

- @uiw/color-convert

## Usage

```tsx
// Installed under your lib alias, e.g. src/lib/color-picker.ts
import { /* exports */ } from "@/lib/color-picker";
```
