# Component Item Keys

Stable key derivation for list-based components such as alert dialog, field, kanban, and split view.

## Install

```bash
kira-kit add @kira-kit/component-item-keys
```

## Usage

```tsx
// Installed under your lib alias, e.g. src/lib/component-item-keys.ts
import { /* exports */ } from "@/lib/component-item-keys";
```
