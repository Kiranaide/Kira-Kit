# Olive Ledger

A cultivated olive theme for research tools, financial workspaces, and sustainability products that value credibility over corporate polish.

## Install

```bash
npx shadcn add @kira-kit/theme-olive-ledger
```

## Usage

```tsx
import { ThemeOliveLedger } from "@/components/ui/theme-olive-ledger";
/* Applied as CSS variables by shadcn. */
```
