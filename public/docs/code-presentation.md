# Code Presentation

Shiki highlighting and Prettier formatting pipeline that powers code block rendering and copy-ready output.

## Install

```bash
kira-kit add @kira-kit/code-presentation
```

## Dependencies

- @shikijs/core
- @shikijs/engine-javascript
- @shikijs/langs
- @shikijs/themes
- prettier

## Usage

```tsx
// Installed under your lib alias, e.g. src/lib/code-presentation.ts
import { /* exports */ } from "@/lib/code-presentation";
```
