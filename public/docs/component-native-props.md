# Component Native Props

Filters custom component props out of native element prop spreads so DOM attributes stay clean.

## Install

```bash
kira-kit add @kira-kit/component-native-props
```

## Usage

```tsx
// Installed under your lib alias, e.g. src/lib/component-native-props.ts
import { /* exports */ } from "@/lib/component-native-props";
```
