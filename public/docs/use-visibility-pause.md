# useVisibilityPause

Provides useDocumentVisible and useVisibilityPause hooks to pause looped animations and timers automatically when the document tab is hidden or the target element is scrolled offscreen.

## Install

```bash
kira-kit add @kira-kit/use-visibility-pause
```

## Usage

```tsx
import { useVisibilityPause } from "@/hooks/use-visibility-pause";
```
