# useAnnounce

Creates provider-free polite and assertive ARIA live regions and returns announce, announcePolite, announceAssertive, and clear functions for screen-reader updates. Use it for dynamic status messages, with defaultPoliteness and debounceMs options to control announcement urgency and rapid updates.

## Install

```bash
npx shadcn add @kira-kit/use-announce
```

## Usage

```tsx
import { useAnnounce } from "@/hooks/use-announce";
```
