# Cryostat

A chilled petrol-cyan theme for data platforms that need the visual discipline of laboratory equipment.

## Install

```bash
npx shadcn add @kira-kit/theme-cryostat
```

## Usage

```tsx
import { ThemeCryostat } from "@/components/ui/theme-cryostat";
/* Applied as CSS variables by shadcn. */
```
