# Low Orbit

A steel-indigo instrument palette for geospatial, aviation, and infrastructure tools built around exact coordinates and layered evidence.

## Install

```bash
npx shadcn add @kira-kit/theme-low-orbit
```

## Usage

```tsx
import { ThemeLowOrbit } from "@/components/ui/theme-low-orbit";
/* Applied as CSS variables by shadcn. */
```
