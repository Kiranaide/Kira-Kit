# Validated Layout Storage

Validated localStorage persistence adapter shared by resizable panel groups and split views.

## Install

```bash
kira-kit add @kira-kit/layout-storage
```

## Registry dependencies

- @kira-kit/component-utils

## Usage

```tsx
// Installed under your lib alias, e.g. src/lib/layout-storage.ts
import { /* exports */ } from "@/lib/layout-storage";
```
