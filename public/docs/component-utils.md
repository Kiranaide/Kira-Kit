# Component Utils

Shared component boundary plumbing: prop type guards, default resolution, native prop filtering, and occurrence-key derivation.

## Install

```bash
kira-kit add @kira-kit/component-utils
```

## Usage

```tsx
// Installed under your lib alias, e.g. src/lib/component-utils.ts
import { /* exports */ } from "@/lib/component-utils";
```
