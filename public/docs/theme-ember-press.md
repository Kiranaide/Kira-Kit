# Ember Press

A burnished terracotta theme for editorial platforms, independent publications, and content-rich products with a confident point of view.

## Install

```bash
npx shadcn add @kira-kit/theme-ember-press
```

## Usage

```tsx
import { ThemeEmberPress } from "@/components/ui/theme-ember-press";
/* Applied as CSS variables by shadcn. */
```
